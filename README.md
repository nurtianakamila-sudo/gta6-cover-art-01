Sunset Cover Studio — turn your photo into GTA-style poster cover art. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Add your photos (or try the samples), click a panel to crop it, edit the title and tagline, pick a colour grade and a post size, and hit Export PNG. Everything runs offline in the page — photos are read on your machine and never uploaded.
